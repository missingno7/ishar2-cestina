ISHAR 2 – ČEŠTINA {VERSION}

1. Rozbalte ZIP a spusťte Ishar2-Cestina.exe.
2. Vyberte složku hry, ve které jsou START.EXE a soubory .IO.
3. Ukončete hru a klikněte na Aplikovat češtinu.
4. Hru spusťte svým obvyklým způsobem v DOSBoxu a vyberte 3 – Čeština.

Program je přenosný, pro 64bitové Windows, bez instalace dalších knihoven.
Toto sestavení není digitálně podepsané.
Nepotřebuje internet, Python ani administrátorská práva. Potřebujete právo
zápisu do složky hry. Pokud ho nemáte, použijte vlastní zapisovatelnou kopii hry.

Podporována je ověřená DOS verze Ishar 2 s angličtinou, francouzštinou
a němčinou. Přesná shoda verze se ověří podle obsahu START.EXE a devíti
měněných souborů. Neznámou verzi ani jinak upravené soubory program nepřepíše.
Označení obchodu nebo název složky samo o sobě kompatibilitu nezaručuje.

Původních devět souborů se uloží do .ishar2-cs-backup-{VERSION} ve složce hry.
Tuto zálohu nemažte. Tlačítko Obnovit originál ji použije pro návrat zpět.
Uložené pozice, nastavení a START.EXE se nemění. Čeština nahrazuje němčinu;
společné popisky a upravené písmo ovlivňují i ostatní volby jazyka.

Balíček obsahuje vlastní instalační program a rozdílová data lokalizace.
Neobsahuje celé herní prostředky, původní EXE, hudbu ani kompletní grafiku.
Původní data rozbalí z vaší hry, změní texty a glyfy a znovu sestaví prostředky.
Ověření instalátoru nenahrazuje kompletní odehrání hry v DOSBoxu.

Pro automatické použití jsou dostupné příkazy:
Ishar2-Cestina.exe --check "cesta ke hře"
Ishar2-Cestina.exe --apply "cesta ke hře"
Ishar2-Cestina.exe --restore "cesta ke hře"
Návratový kód 0 znamená úspěch, 1 chybu. Bez parametrů se otevře okno.
